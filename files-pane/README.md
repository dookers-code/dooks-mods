# files-pane

A Claude Code mod that adds a **Files** pane to the desktop app and the terminal. It shows what Claude is doing and what changed, next to the conversation.

## Requirements

- Claude Code 2.1.275 or later.
- `git` on your PATH. The status card and Git changes run git commands in the project you open.
- Developed and tested on the **desktop app**. It should also draw in the terminal, but that surface is untested.

## Install

`/plugin install` only works in a terminal Claude Code session (not the desktop Code tab), but once installed the pane loads in the desktop app too.

In a terminal session:

```
/plugin install files-pane --marketplace dookers-code/dooks-mods
```

Answer `y` to add the marketplace, then choose the user scope.

## Use

Open the pane with:

```
/file-pane
```

- **Status card**: what Claude is reading or editing right now, the branch, and the uncommitted count.
- **Claude touched**: files Claude read (Opened) or changed (Edited). Click a name to preview it.
- **Git changes**: every uncommitted file with `+N -M` counts, a total, and an inline diff. Use *Expand all diffs* to see the whole `git diff`.
- **All files**: a tree with file-type icons, search, size and hidden-file toggles. Click a name to preview a file; a changed file opens as a diff with a Changes / File toggle.

## Update and remove

```
claude plugin marketplace update dooks-mods
claude plugin update files-pane
claude plugin uninstall files-pane
```

Restart Claude Code after an update.

## Known limits

- The file tree is capped at 120 rows (and previews at 120 lines). The desktop silently drops a pane whose tree is too large, so collapse folders or search to see more.
- **Claude touched** only sees changes made while the mod is loaded, and it resets when the mod reloads.
- Edits made by shell commands are detected by comparing `git status` before and after each tool call. A change you make yourself during a tool call can be wrongly credited to Claude. Files only *read* through a shell command are not tracked.
- Git views compare against `HEAD`, so they also include changes made before the session started.

## Stability

This mod uses Claude Code's early-access function-hooks API, which can change between releases and break the mod. If the pane stops drawing after an update, check for a newer version of this repo.

## Develop

```
claude --plugin-dir ./files-pane
claude plugin validate ./files-pane
```

`.claude-plugin/types/` is generated by Claude Code and is git-ignored.
