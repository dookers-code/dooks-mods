# files-pane

A Claude Code mod that adds a Files pane to the desktop app and terminal:

- A status card: what Claude is reading or editing right now, the branch, and the uncommitted count
- **Claude touched**: files Claude read or edited, with Opened/Edited pills
- **Git changes**: every uncommitted file with `+N -M` counts and an inline diff
- **All files**: a file tree with type icons, search, and an inline preview

Open it with `/files`.

## Install

In a terminal Claude Code session:

```
/plugin install files-pane --marketplace jfuqua390/dooks-mods
```

Answer `y` to add the marketplace, then pick the user scope. It also loads in the desktop app's Code tab.

## Develop

```
claude --plugin-dir ./files-pane
claude plugin validate ./files-pane
```

`.claude-plugin/types/` is generated by Claude Code and is git-ignored.

## Notes

- The tree is capped at 120 rows; the desktop silently drops a pane whose tree is too large.
- File-type icons are inline SVGs. Check each logo's license and trademark before publishing publicly.
